# 💎 Sunshine Acessórios — Controle de Clientes

Sistema web responsivo desenvolvido para gerenciamento rápido de clientes, vendas e controle financeiro de uma loja de acessórios.

## 🚀 Funcionalidades
* **Autenticação Segura:** Acesso restrito via login e senha.
* **Consulta Instantânea:** Busca em tempo real pelo nome da cliente.
* **Controle Financeiro:** Sinalização visual de pagamentos (Pago / Devendo) e registro de forma de pagamento (Pix, Cartão, Dinheiro).
* **Integração com WhatsApp:** Botão direto para iniciar conversa com a cliente cadastrada.
* **Histórico Automático:** Registro de data e hora exatas de cada venda.

## 🛠️ Tecnologias Utilizadas
* HTML5, CSS3 e JavaScript (Vanilla)
* Firebase Authentication
* Cloud Firestore (Banco de Dados NoSQL)
* GitHub Pages
